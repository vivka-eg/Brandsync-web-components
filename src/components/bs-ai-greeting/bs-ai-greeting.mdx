## Overview

The centered welcome heading shown at the top of an empty Genie AI chat panel: a bold "Hi. I'm
`assistantName`, your AI assistant." heading plus a "How can I help you with `productName` today?"
subtext.

**When to use**
- The empty/initial state of a Genie AI chat panel, before the user has sent a message.

**When not to use**
- Once a conversation has started — this is a one-time empty-state greeting, not a persistent
  header (see `bs-chatbot-header` for that).

## Without product name

`productName` is optional. Figma's copy has a `[product_name]` placeholder for the consuming app
to fill in, but omitting it falls back to a product-agnostic subtext instead of rendering an empty
placeholder.

## Component API

<Controls of={AiGreetingStories.Default} />

**Customization surface** (see `CONVENTIONS.md` in the repo root for the full convention):
- Slots: none
- Shadow parts: `::part(heading)`, `::part(subtext)`
- CSS custom properties: `--bs-ai-greeting-gap`, `--bs-ai-greeting-max-width`,
  `--bs-ai-greeting-heading-color`, `--bs-ai-greeting-heading-font-size`,
  `--bs-ai-greeting-heading-line-height`, `--bs-ai-greeting-heading-weight`,
  `--bs-ai-greeting-heading-gap`, `--bs-ai-greeting-subtext-color`,
  `--bs-ai-greeting-subtext-font-size`, `--bs-ai-greeting-subtext-line-height`

## Accessibility

- Renders as plain centered text with no interactive elements — no extra ARIA is needed.
- The heading uses `<p>` tags, not `<h1>`/`<h2>`, since this is decorative empty-state copy, not a
  page/section heading a screen reader user would navigate to via heading shortcuts.
