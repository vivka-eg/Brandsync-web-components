## Overview

A star-rating feedback card shown at the end of a Genie AI chat: a heading/subtitle, a 5-star
rating, an optional comment, and either "Submit feedback" + "Start new chat" (before submitting)
or just "Start new chat" (after).

**When to use**
- Prompting for feedback on a Genie response or chat session, typically after the user ends or
  restarts a conversation.

**When not to use**
- A generic star-rating input elsewhere in the product — this component's copy and layout are
  purpose-built for the Genie feedback flow, not a reusable rating control.

## Submitted

The heading and subtitle aren't freeform — before submitting they're always the fixed "How was
your experience..." copy; after submitting, they're determined entirely by the rating (1-2 stars
reads apologetic, 3 neutral, 4-5 positive), matching the source design exactly. "Start new chat"
also switches from outlined to the primary (filled) treatment once it's the only action left.

## Events

| Event             | Fires when                                    | Payload                             | Cancelable |
| ----------------- | ---------------------------------------------- | ------------------------------------ | ---------- |
| `bsRatingChange`  | A star is clicked (before submitting)          | `number` (1-5)                       | No         |
| `bsCommentInput`  | Every keystroke in the comment textarea        | `string` (current value)             | No         |
| `bsSubmit`        | "Submit feedback" is clicked                   | `{ rating: number, comment: string }`| No         |
| `bsNewChat`       | "Start new chat" is clicked                    | `void`                               | No         |
| `bsClose`         | The close button is clicked                    | `void`                               | No         |

## Accessibility

- The five stars form a `role="radiogroup"` of `role="radio"` buttons with `aria-checked`, so
  assistive tech announces the rating as a single choice among 5, not five independent toggles.
- Stars are natively `disabled` once `submitted` is true, so they're unreachable by keyboard and
  clicks are no-ops — not just visually inert.
- "Submit feedback" is natively `disabled` until a rating is given, preventing an empty submission.
- The close button has a fixed `aria-label="Close"` since it's icon-only.
- This component does not remove or reset itself in response to any event — the consuming app owns
  visibility (in response to `bsClose`) and resetting `rating`/`submitted`/`comment` (in response
  to `bsNewChat`).
