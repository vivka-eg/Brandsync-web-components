## Overview

The top-level navigation bar for a page: the BrandSync logo plus two consumer-provided slots for
menu/action content.

**When to use**
- The persistent top bar of an application, above the page content.

**When not to use**
- The header of a Genie AI chat panel -- use `bs-chatbot-header` instead, which is purpose-built
  for that narrower layout and its own fixed action buttons.

## Dark background

This story wraps the bar in a `data-theme="dark"` element, which flips
`--bs-navigation-header-bg`/`--bs-navigation-header-border` and every text-color token this bar's
slotted content relies on, all via ordinary CSS custom property inheritance -- no per-component
changes needed. (This library also exposes a global "Theme" switch in Storybook's own toolbar for
browsing every component under one ambient theme -- but a single story can't use that switch itself
without also flipping every *other* story on this same Docs page, since they all share one
document.) `logoBackground` defaults to `"auto"`, which reacts to the same `data-theme` attribute
via a small CSS bridge (see `bs-logo`'s own docs), so the logo automatically swaps to a real
separate white-wordmark asset too -- this story doesn't set `logoBackground` at all. Only set it to
`"light"`/`"dark"` explicitly if you've put the bar on a dark surface WITHOUT setting
`[data-theme="dark"]` (e.g. a hardcoded dark background), so the logo has no ambient theme to
follow.

<Canvas of={NavigationHeaderStories.HeaderBaseDark} />

## Skip to content

Set `skipToContentHref` to the id of your page's main content landmark (e.g. `#main-content`) to
render a "Skip to main content" link -- offscreen by default, brought into view on keyboard focus,
matching the standard skip-link pattern (Carbon's UI Shell calls this `cds-skip-to-content`). It's
opt-in rather than pointing at a guessed default id, since a skip link to a target that doesn't
exist on your page silently does nothing when activated. Tab into the story below to see it.

<Canvas of={NavigationHeaderStories.HeaderBaseWithSkipLink} />

## Actions and switcher

`left`/`right` slot content isn't limited to buttons/tabs/tooltips -- click the grid icon (next to
Notifications) to open a workspace/account "switcher" panel sliding in from the right edge of the
viewport. This isn't a real `bs-*` component (no generic slide-in-from-right panel exists in this
library yet -- `bs-dialog` is a centered dialog, not this), so it's plain story-only markup
demonstrating what a consumer can build with the `right` slot's freedom.

## Component API

**Customization surface** (see `CONVENTIONS.md` in the repo root for the full convention):
- CSS Custom Properties: `--bs-navigation-header-bg`, `--bs-navigation-header-border`,
  `--bs-navigation-header-padding-top`, `--bs-navigation-header-padding-bottom`,
  `--bs-navigation-header-padding-x`, `--bs-navigation-header-max-width`,
  `--bs-navigation-header-item-gap`, `--bs-navigation-header-slot-gap`,
  `--bs-navigation-header-skip-link-bg`, `--bs-navigation-header-skip-link-color`
- Props: `alignment`, `ariaLabel`, `skipToContentHref`, `skipToContentLabel`, `logoBackground`
  (forwarded to the internal `bs-logo`'s own `background` prop -- see "Dark background" above)
- Slots: `left`, `right`
- Shadow parts: `::part(logo)`, `::part(left)`, `::part(right)`, `::part(skip-link)`

## Accessibility

- Renders a real `<header>` element, which carries the implicit `banner` landmark role as long as
  it isn't nested inside an `<article>`/`<section>` -- no extra `role` attribute needed.
- Set `ariaLabel` when a page has more than one `<header>` landmark (e.g. this one plus a
  page-specific sub-header), so screen reader users can tell them apart in the landmarks list.
- The logo is a decorative brand mark rendered with `role="img"` and a plain `aria-label="BrandSync"`
  -- it isn't a link back to the homepage by itself; wrap it yourself (e.g. an `<a>` around the
  whole `bs-navigation-header`, or via the `logo` shadow part) if your app needs that behavior.
- The skip-to-content link (when `skipToContentHref` is set) is the first element inside the
  `<header>`, ahead of the logo and both slots, so it's the first thing a keyboard user tabs to.
