## Overview

A small status or category pill, usually paired with a label or list item.

**When to use**
- Communicating a short, fixed status (e.g. "Active", "On leave") or category label.

**When not to use**
- As an interactive/clickable element — a badge is a label, not a control. Use a button or chip
  component if it needs to be clickable.
- For long text — badges are sized for one or two words.

## Accessibility

- Renders as a plain `<span>` — purely informational text, not an interactive element, so it
  needs no keyboard handling or ARIA role by default.
- Every variant's text/background pairing comes from `brandsync-tokens`' semantic color scale,
  which ships pre-computed WCAG contrast ratios (`accessibility.json`) — this component doesn't
  independently re-verify contrast, it inherits whatever the token pairing provides.
- If a badge communicates a status change that should be announced live (e.g. updating from
  "Pending" to "Active" without a page reload), wrap it with `aria-live="polite"` at the point
  where it's used — this component doesn't add that itself, since not every usage is dynamic.
