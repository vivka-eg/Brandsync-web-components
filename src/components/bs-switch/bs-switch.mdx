## Overview

A toggle switch for an on/off setting that takes effect immediately (no explicit form submission
required).

**When to use**
- A binary setting that applies right away (e.g. "Enable notifications", "Dark mode").

**When not to use**
- A binary choice that's part of a form submitted later, or one item within a group of
  independent choices -- use `bs-checkbox` instead.
- A single mutually-exclusive choice from a set -- use a radio group instead.

## Accessibility

- Renders a real `<input type="checkbox" role="switch">`, visually hidden (`opacity: 0`, not
  `display: none`) so it stays focusable and keyboard-operable (Space toggles it, same as any
  native switch).
- The native input is wrapped in a `<label>` together with the visual track/knob and label text,
  so clicking anywhere in the component toggles it -- no separate `for`/`id` wiring needed.
- `disabled` sets the native `disabled` attribute, which removes the control from the tab order and
  is announced by assistive technology automatically -- no separate `aria-disabled` is added.
- **Required whenever the default (label) slot is empty:** set `ariaLabel` (e.g. a bare "enabled"
  switch in a table row). Setting a plain `aria-label` HTML attribute on the `<bs-switch>` host does
  **not** work -- that attribute never crosses into the shadow DOM, so the actual focusable native
  `<input>` stays nameless. Same prop/pattern as `bs-checkbox`'s identical `ariaLabel` prop.
