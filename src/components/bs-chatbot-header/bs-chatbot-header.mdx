## Overview

The header bar that sits above `bs-composer` in a Genie AI chat panel: the Genie brand mark on
the left and four fixed actions (new chat, history, expand, close) on the right.

**When to use**
- The top bar of a Genie AI chat panel, directly above a `bs-composer`.

**When not to use**
- A generic app/page header — this component's layout and actions are purpose-built for the
  Genie chat panel, not a general navigation bar.

| Event       | Fires when                          | Payload | Cancelable |
| ----------- | ------------------------------------ | ------- | ---------- |
| `bsNewChat` | The "New chat" button is clicked     | `void`  | No         |
| `bsHistory` | The "History" button is clicked      | `void`  | No         |
| `bsExpand`  | The "Expand" button is clicked       | `void`  | No         |
| `bsClose`   | The "Close" button is clicked        | `void`  | No         |

## Accessibility

- The header renders with `role="banner"` and an `aria-label` sourced from the `heading` prop
  (default `"Genie"`), giving assistive technology an accessible name for the landmark.
- The logo image's `alt` text also uses `heading`, so overriding it (e.g. to `"Support"` for a
  human-support variant of the panel) updates both the landmark name and the image's accessible
  name together.
- Each of the four icon buttons has a fixed, descriptive `aria-label` ("New chat", "History",
  "Expand", "Close") since they're icon-only with no visible text.
